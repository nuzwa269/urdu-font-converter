اردو نستعلیق فلوٹنگ ٹول + Urdu Font Converter shortcode/block ایک ہی پلگ ان میں۔

== Description ==
یہ پلگ ان دو ٹولز فراہم کرتا ہے:

1. **نستعلیق فلوٹنگ ٹول** — کسی بھی صفحے پر ایک فلوٹنگ بٹن جس سے وزٹرز فونٹ سائز، لائن ہائٹ، وزن اور ڈارک موڈ کنٹرول کر سکتے ہیں۔
2. **Urdu Font Converter** — `[urdu_converter]` shortcode یا Gutenberg block جو 7 خوبصورت اردو فونٹس میں متن دکھاتا ہے، پریسٹس، فریمز، رنگ، اور PNG ڈاؤن لوڈ کی سہولت دیتا ہے۔

== Installation ==
1. ZIP فائل ڈاؤن لوڈ کریں۔
2. WP Admin → Plugins → Add New → Upload Plugin سے اپ لوڈ کریں۔
3. Activate کریں۔
4. **Settings → اردو ٹولز** سے ترتیبات تبدیل کریں۔
5. کسی بھی پوسٹ/پیج میں `[urdu_converter]` لکھیں یا Gutenberg میں "Urdu Font Converter" block منتخب کریں۔
